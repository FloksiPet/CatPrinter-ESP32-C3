# 🖨️ Cat Printer ESP32-C3 Firmware v1.0

Firmware для **ESP32-C3** для спілкування з дешевим портативним термічним принтером **GB01** (Cat Printer) через **Bluetooth Low Energy (BLE)**.

## 📋 Характеристики

- ✅ BLE комунікація з принтером
- ✅ Автоматичне переконектування при розриві зв'язку
- ✅ Управління енергією та якістю друку
- ✅ Прокручування паперу (витягування/втягування)
- ⚠️ **В1.0**: Успішна прокрутка паперу - тестування основної комунікації

## 🛠️ Апаратне забезпечення

### Потрібні компоненти:
- **ESP32-C3 Dev Module** (або сумісна плата з ESP32-C3)
- **GB01 Cat Printer** з BLE (часто називають "Cat Printer" або "Meow Printer")
- USB кабель Micro-USB для прошивання ESP32
- Батарея або USB для живлення принтера

### Підключення:
- Без додаткових дротів! Все працює через BLE (Bluetooth Low Energy)
- Обидва пристрої повинні мати батарею/живлення

## 🔧 Інсталяція

### Крок 1: Встановлення Arduino IDE

1. Завантаж [Arduino IDE 1.8.x+](https://www.arduino.cc/en/software)
2. Встановлю бібліотеку для ESP32:
   - В меню: **Файл → Налаштування**
   - У полі "Додаткові URL-адреси менеджера плат" добавь:
   ```
   https://dl.espressif.com/dl/package_esp32_index.json
   ```
   - Клікни OK
   - **Інструменти → Плата → Менеджер плат**
   - Пошук "esp32" → Знайди "esp32 by Espressif Systems"
   - Клікни "Встановити"

### Крок 2: Вибір плати в Arduino IDE

В Arduino IDE:
- **Інструменти → Плата → esp32 → ESP32C3 Dev Module**
- **Інструменти → Частота CPU → 160MHz (WiFi)**
- **Інструменти → Flash Size → 4MB (32Mb)**
- **Інструменти → SPIFFS Size → 1.9MB APP with OTA/190KB SPIFFS**
- **Інструменти → Upload Speed → 115200**
- **Інструменти → Port → COM[X]** (вибір порту, де підключена плата)

### Крок 3: Завантаження коду

1. Клонуй репо:
```bash
git clone https://github.com/FloksiPet/CatPrinter-ESP32-C3.git
cd CatPrinter-ESP32-C3
```

2. Відкрий `ESP32_MX10_Gateway_1.0.ino` в Arduino IDE

3. **ВАЖЛИВО: Знайди і змініть MAC адресу твого принтера:**

```cpp
static std::string PRINTER_MAC = "3e:01:22:4a:a2:05";  // ← ЗМІНІТЬ НА ВАШУ!
```

**Як дізнатися MAC адресу принтера?**
- Увімкни Bluetooth на своєму телефоні
- Знайди принтер в доступних пристроях (часто називається "GB01", "Meow", "Cat Printer" або подібне)
- MAC адреса написана як: `XX:XX:XX:XX:XX:XX`
- Скопіюй її в код

4. Підключи ESP32 до ПК через USB

5. В Arduino IDE клікни **Sketch → Upload** (або Ctrl+U)

6. Дочекайся написання

## 📡 Використання

### Перший запуск:

1. Підключи ESP32 до USB
2. Відкрий **Інструменти → Монітор послідовного портуу** (115200 бод)
3. Натисни кнопку RESET на платі ESP32
4. В монітор мають прийти логи

### Якщо принтер не підключується:

❌ **"❌ Підключення не вдалось"**
- Перевір MAC адресу
- Упевниться, що принтер увімкнений
- Спробуй перезагрузити обидва пристрої
- Перевір дальність (BLE працює до 10-20 метрів)

❌ **"❌ Сервіс не знайдено"**
- Принтер підключився, але стек BLE не響ає
- Це може бути проблемою з прошивкою принтера
- Спробуй оновити прошивку принтера через оригінальний додаток

❌ **"❌ Дроп на [команда]"**
- З'єднання розірвалося під час комунікації
- Збільш дилеї в коді (параметр `delay()`)

## 📊 Протокол принтера

### Формат пакету:
```
[0x51] [0x78] [CMD] [0x00] [LEN] [0x00] [DATA...] [CRC8(DATA)] [0xFF]
```

**Складові:**
- `0x51 0x78` - Magic number (завжди однаковий)
- `CMD` - Команда (див. таблицю нижче)
- `0x00` - Резервне поле
- `LEN` - Довжина даних (кількість байт)
- `0x00` - Резервне поле
- `DATA` - Параметри команди (опціонально)
- `CRC8` - Контрольна сума даних
- `0xFF` - Маркер кінця пакету

### Команди:

| Команда | Код | Дані | Опис |
|---------|-----|------|------|
| RetractPaper | `0xA0` | 2 байти | Втягнути папір назад (кількість кроків) |
| FeedPaper | `0xA1` | 2 байти | Витягнути папір вперед (кількість кроків) |
| DrawBitmap | `0xA2` | 50 байт | Намалювати лінію (400 пікселів, 1 бит на піксель) |
| GetStatus | `0xA3` | нема | Отримати статус принтера |
| SetQuality | `0xA4` | 1 байт | Встановити якість друку (1-5) |
| SetEnergy | `0xAF` | 2 байти | Встановити рівень енергії (0x10 0x00 = середня) |
| DrawingMode | `0xBE` | 1 байт | Режим: 0=Зображення, 1=Текст |

### Приклад: FeedPaper на 30 кроків

```
51 78 A1 00 02 00 00 1E 5A FF
│  │  │  │  │  │  │  │  │  └─ 0xFF (конец)
│  │  │  │  │  │  │  │  └─────── CRC8 = 0x5A
│  │  │  │  │  │  │  └────────── 0x1E = 30 (LOW byte)
│  │  │  │  │  │  └───────────── 0x00 (HIGH byte)
│  │  │  │  │  └──────────────── резерв
│  │  │  │  └─────────────────── 0x02 (LEN = 2 байти)
│  │  │  └────────────────────── резерв
│  │  └───────────────────────── 0xA1 (FeedPaper)
│  └──────────────────────────── 0x78
└─────────────────────────────── 0x51 (Magic)
```

## 🐛 Відомі проблеми та рішення

### Проблема: Принтер не друкує
- ✓ В версії 1.0 код тільки тестує прокрутку паперу
- ✓ Друк потребує налагодження конвертації зображення
- **Рішення**: Жди версії 2.0 з повною підтримкою друку

### Проблема: BLE розривається через кілька секунд
- Можлива проблема з живленням ESP32
- Спробуй добавити конденсатор 100µF на живлення
- Збільш дилеї між командами (у коді)

### Проблема: Serial Monitor показує тільки тирета (═══)
- Неправильна швидкість Serial (повинна бути 115200)
- Клікни вниз справа в Serial Monitor і вибери 115200

### Проблема: Загружение зависает
- Переведи ESP32 в режим DFU (Download Mode):
  - Утримай кнопку BOOT
  - Клікни RESET
  - Відпусти BOOT
  - Спробуй знову завантажити
